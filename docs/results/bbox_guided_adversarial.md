# BBox 유도 재추론 결과

## 연구 질문

OWLv2가 찾은 객체 후보 영역을 Qwen2.5-VL에 표시하면 객체 존재 환각이 감소하는가?

## 실험 설정

- VLM: Qwen2.5-VL-3B-Instruct
- Grounder: OWLv2-base-patch16-ensemble
- 데이터: COCO-POPE adversarial
- 전체 크기: 이미지 500장과 질문 3,000개
- 평가 크기: test 이미지 400장과 질문 2,400개
- Split: 이미지 단위 20% dev와 80% test, seed 42
- 생성 방식: greedy decoding, 최대 4 tokens

OWLv2가 후보 영역을 반환하면 원본 이미지에 빨간 BBox를 표시했다. Qwen에는 BBox가 detector의 후보일 뿐이며 객체 존재를 증명하지 않는다고 설명했다.

사용 가능한 BBox가 없으면 원본 이미지를 그대로 제공했다. 또한 detector 결과가 틀릴 수 있으므로 전체 이미지를 직접 확인하도록 요청했다.

Test 질문 2,400개 중 2,093개에는 사용 가능한 BBox가 있었다. 나머지 307개에는 BBox가 없었다.

## Test 결과

표의 값은 백분율이다.

| 방법 | Accuracy | Precision | Recall | F1 | FPR |
|---|---:|---:|---:|---:|---:|
| 기존 Qwen | **86.54** | **93.98** | 78.08 | **85.30** | **5.00** |
| BBox 유도 Qwen | 84.00 | 85.11 | **82.42** | 83.74 | 14.42 |

BBox 유도 조건은 기존 답변 285개를 변경했다.

- 오답을 정답으로 수정: 112개
- 정답을 오답으로 변경: 173개
- False positive 수정: 15개
- False negative 수정: 97개
- True positive 손실: 45개
- True negative 손실: 128개

Accuracy는 2.54%p 감소했다. Recall은 4.33%p 증가했다. FPR은 9.42%p 증가했다.

## BBox가 있는 질문

사용 가능한 BBox가 있는 2,093개 질문만 비교했다.

| 방법 | Accuracy | Precision | Recall | F1 | FPR |
|---|---:|---:|---:|---:|---:|
| 기존 Qwen | **85.14** | **94.07** | 78.79 | **85.75** | **6.52** |
| BBox 유도 Qwen | 82.61 | 85.83 | **83.08** | 84.43 | 18.01 |

BBox는 일부 false negative를 수정했다. 그러나 잘못된 후보 영역도 객체 존재의 시각적 암시로 작동했다. 그 결과 Qwen의 `Yes` 비율과 false positive가 증가했다.

## 해석

단순 BBox 표시는 환각 완화 방법으로 충분하지 않았다. 위치 강조는 작은 객체를 다시 보게 해 recall을 높일 수 있다. 그러나 detector가 잘못 찾은 영역에도 빨간 상자가 생긴다. Qwen은 이 표시를 객체 존재의 근거로 과신할 수 있다.

이 결과는 detector 정보를 VLM에 제공하는 방식이 중요하다는 점을 보여준다. 외부 grounding 정보는 자동으로 성능을 높이지 않는다. 잘못된 grounding은 새로운 오류를 만들 수 있다.

## 한계

이 조건은 이미지와 프롬프트를 동시에 변경했다. 따라서 성능 변화가 BBox 위치 정보 때문인지, 빨간 상자라는 시각적 강조 때문인지, detector를 언급한 프롬프트 때문인지 완전히 분리할 수 없다.

POPE는 객체 존재 여부만 평가한다. 이 결과를 속성, 관계, 개수 또는 개방형 생성 환각에 바로 적용할 수 없다.

## 다음 대조 실험

다음 조건을 같은 test split에서 비교한다.

1. 원본 이미지에 같은 유도 프롬프트만 제공한다.
2. 같은 크기의 BBox를 임의 위치에 표시한다.
3. 원본 이미지와 OWLv2 BBox crop을 함께 제공한다.

이 비교는 프롬프트 암시, 일반적인 시각적 강조, 정확한 위치 정보의 효과를 분리한다.
